## 📖 Tentang Proyek

**Ayra Kids** adalah website edukasi interaktif yang dirancang khusus untuk anak-anak usia **4–8 tahun**. Website ini membantu anak mengenal huruf, angka, warna, dan berbagai permainan edukatif dengan cara yang menyenangkan.

Seluruh website dibangun **100% menggunakan HTML5, CSS3, dan JavaScript Vanilla** — tanpa framework, tanpa database, dan tanpa server. Cukup buka `index.html` di browser, website langsung berjalan.

---

## ✨ Fitur Utama

| Fitur | Deskripsi |
|-------|-----------|
| 🔤 **Belajar Huruf** | Mengenal huruf A–Z dengan gambar & suara |
| 🔢 **Belajar Angka** | Mengenal angka 1–20 dengan benda & suara |
| 🎯 **Tebak Huruf** | Game interaktif menebak huruf dengan skor |
| 🎲 **Tebak Angka** | Game menghitung & menebak angka |
| 🎨 **Mewarnai** | Mewarnai gambar SVG dengan 20 pilihan warna |
| 🎮 **Permainan** | Piano virtual & mini game edukatif |
| 🔊 **Text-to-Speech** | Semua konten diucapkan dalam Bahasa Indonesia |
| 📱 **Responsif** | Tampil optimal di HP, tablet, dan desktop |
